# Toastium 
(pronounced Toast-Is-Utterly-aMazing)

Operating system that I have been developing for learning purposes. 

The operating system is designed to run on RISC-V however currently because of many inaccuracies it won't currently run on real hardware. A port is planned once I learn enough and get enough of the OS done for it to be worth it (or I might start from scratch, not sure yet)
