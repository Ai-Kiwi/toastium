# Toastium 
(pronounced Toast-Is-Utterly-aMazing)

An operating system that I have been developing for learning purposes. 

The operating system is designed to run on RISC-V; however, due to many inaccuracies, it currently won't run on real hardware. A port is planned once I learn enough and get enough of the OS done for it to be worth it (or I might start from scratch, not sure yet)

If you are interested in reading about this project, the devlogs can be found at: https://github.com/Ai-Kiwi/ai-kiwi-devlog/tree/main/toastium
